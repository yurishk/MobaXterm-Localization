MobaXterm 26.5 简体中文资源汉化预览版
====================================

使用：
1. 将整个压缩包解压到独立目录，建议使用当前用户可写的位置。
2. 保持 EXE、CygUtils.plugin、CygUtils64.plugin 在同一目录。
3. 运行 MobaXterm_26.5_zh-CN.exe。

本版本为社区资源汉化，部分工具栏、主页按钮和动态文本仍可能为英文。
注意本项目非 Mobatek 官方发行版，不提供注册、破解、功能解锁或授权绕过。
由于修改了界面资源，生成程序不再拥有原厂有效数字签名。
请阅读同目录 KNOWN_ISSUES.md、THIRD_PARTY_NOTICES.md 和构建报告。
