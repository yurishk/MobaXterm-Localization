# MobaXterm 26.5 简体中文资源汉化预览版

适配 MobaXterm Home Edition **26.5 / build 5542**。

- 复用 RipplePiam 项目中适用于新版的界面译文，并补充智能卡、Windows SSH Agent、WebAuthn、CSV 导入、粘贴确认等新版文本。
- 替换 2,257 处文字，其中窗体/菜单/提示 1,878 处、字符串表 333 处、运行时显示常量 46 处。按出现位置计数。
- 补充顶部工具栏、主页“打开本地终端”和“新建会话”、快速连接与会话搜索占位文字、欢迎提示，以及用户会话根节点及其查找引用。
- 构建工具和词典分离，可生成其他语言模板并独立构建；本次仅提供简体中文成品。
- 附带构建报告及 SHA-256 校验文件；

## 使用

下载并解压 `MobaXterm-Home-26.5-zh-CN-portable.zip`，运行 `MobaXterm_26.5_zh-CN.exe`。保持两个 CygUtils 插件与 EXE 在同一目录。


## 已知限制

未纳入已核对清单的动态文案及内嵌工具仍可能为英文，需要测试反馈。
